# ADR NNNN: Decision title

- Status: proposed
- Date: YYYY-MM-DD
- Owners: team or individuals responsible for the decision and operation

## Context

Describe the measured problem, constraints, current behavior, affected modules,
data owners, consumers, and why a smaller in-process change is insufficient.

## Decision

State the chosen option, synchronous and asynchronous contracts, dependency
direction, data ownership, security boundary, and operational ownership.

## Alternatives considered

List viable alternatives and the concrete reason each was rejected.

## Consequences

Record expected benefits, recurring cost, failure modes, compatibility impact,
and required observability or runbooks.

## Rollout and rollback

Define measurable success criteria, migration and verification steps, staged
traffic cutover, rollback triggers, rollback owner, and temporary components
with removal dates.
